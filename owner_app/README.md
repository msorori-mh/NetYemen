# NetYemen Owner

تطبيق أصحاب الشبكات (Android) — الجزء الثالث من منصة NetYemen، مستقل تماماً عن
تطبيق العميل (`../lib`) ولوحة الإدارة (`../admin`). يتصل بنفس مشروع Supabase
عبر RPCs موجودة فعلاً فقط؛ لا يعدّل أي شيء في قاعدة البيانات.

## التشغيل

```bash
cd owner_app
flutter pub get
flutter run
```

## الحالة الحالية (موجة الأساس — NY-OWNER-001)

- تسجيل دخول بهاتف + رمز تحقق (نفس آلية تطبيق العميل).
- حاجز دور: بعد الدخول، يجب أن يملك المستخدم شبكة واحدة فعلاً
  (`get_owned_networks()` غير فارغة) وإلا يُعاد تسجيل خروجه.
- شريط تنقّل سفلي بأربعة أقسام: الرئيسية (محتوى حقيقي — قائمة الشبكات)،
  شبكاتي، المخزون، المبيعات (الثلاثة الأخيرة عناصر نائبة "قريباً").

الميزات المتبقية (`F-OWN-01` إلى `F-OWN-09` في
`docs/NETYEMEN-PRODUCT-REQUIREMENTS-01.md`) تُبنى في موجات لاحقة.
