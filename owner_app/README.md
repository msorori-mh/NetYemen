# واصل نت للملاك (Owner App)

تطبيق Android لأصحاب شبكات الواي فاي على منصة واصل نت. تطبيق Flutter مستقل
(الحزمة `owner`، المعرّف `com.netyemen.owner`) عن تطبيق العميل (`../lib`) ولوحة
الإدارة، ويتصل بنفس مشروع Supabase. يستخدم Riverpod لإدارة الحالة، وكل العمليات
الحساسة تمر عبر RPCs والصلاحيات تُفرض على الخادم (RLS).

## الدخول والحواجز

1. **تسجيل الدخول عبر Google** (Supabase OAuth مع PKCE، والعودة عبر الرابط
   `com.netyemen.owner://login-callback`). لا يوجد دخول بالهاتف/OTP.
2. **رمز الدخول PIN** (6 أرقام، يُتحقق منه على الخادم): يُطلب إعداده عند أول
   دخول، ثم يُطلب:
   - بعد كل تسجيل دخول جديد (تسجيل الخروج يمسح ثقة الجهاز)،
   - وبعد 15 دقيقة خمول، سواء بقي التطبيق في الخلفية أو أُغلق وأعيد فتحه
     (وقت آخر نشاط محفوظ على الجهاز، وأي خطأ في قراءته يعني "مقفل").
3. **حاجز الدور**: من يملك شبكة يدخل التطبيق؛ من يحمل دور `network_owner` بلا
   شبكة يرى نموذج "إنشاء شبكتك الأولى" (تُراجعها الإدارة)؛ غير ذلك تظهر شاشة
   "حسابك ليس صاحب شبكة".

المسار الجذر (`SplashScreen`) هو الوحيد الذي يتفاعل مع حالة المصادقة. تسجيل
الخروج يتم عبر `signOutOwner` فقط، وجذر التطبيق يُبطل كل بيانات المالك عند
تغيّر المستخدم (`invalidateOwnerData`) — أي مزوّد بيانات جديد يجب أن يُضاف هناك.

## الميزات

- **الرئيسية**: شبكات المالك وحالتها (نشطة، قيد الاعتماد، موقوفة…).
- **شبكاتي**: باقات كل شبكة (إنشاء، تعديل، نشر، تعطيل) وأسماء الواي فاي SSID.
  يُدخل المالك الاسم الظاهر فقط؛ الخادم يحسب الاسم الموحّد ويبقى الاسم بانتظار
  اعتماد الإدارة.
- **المخزون**: أرصدة الباقات وحالات الكروت، ورفع دُفعات الكروت:
  - تحقق محلي قبل الرفع (قص، حذف الفارغ والمكرر، رفض ما يزيد على 64 خانة أو
    يحتوي مسافات، حد أقصى 5000 كرت) مع عرض الأعداد وأرقام الأسطر فقط — لا
    تُطبع أرقام الكروت على الشاشة.
  - كل دفعة تُرسل بمفتاح عدم تكرار (`p_batch_key`)، فإعادة المحاولة بعد خطأ
    أو انقطاع لا ترفع الكروت مرتين، والخادم يتخطى الكروت الموجودة مسبقاً.
  - تاريخ الانتهاء الاختياري يُرسل كنهاية اليوم المختار بتوقيت UTC.
- **المبيعات**: الملخص التجاري والتسويات وتفاصيلها (للعرض فقط).

كل المبالغ بالريال اليمني كأعداد صحيحة.

## التشغيل

```bash
cd owner_app
flutter pub get
flutter run
```

لا توجد `--dart-define` مطلوبة: عنوان Supabase والمفتاح العام (publishable)
معرّفان في `lib/utils/constants.dart`.

## الفحوص

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze lib test
flutter test
```

تعمل نفسها في `.github/workflows/owner-app-ci.yml` مع بناء `apk --debug`.
فحص التنسيق (`dart format`) إلزامي في CI.
الاختبارات لا تحتاج Supabase: تغطي تحليل دُفعة الكروت، رسائل الأخطاء، قرار قفل
الـ PIN، وتحليل نموذج الشبكة.

## الأمان على Android

- النافذة كلها `FLAG_SECURE` (لا لقطات شاشة ولا تسجيل، ولا معاينة في قائمة
  التطبيقات الأخيرة) لأن أرقام الكروت تُكتب وتُعرض هنا.
- النسخ الاحتياطي ونقل البيانات بين الأجهزة معطّلان
  (`allowBackup="false"` و `res/xml/data_extraction_rules.xml`).

## توقيع الإصدار (release)

بناء release **يفشل** إن لم يتوفر مفتاح التوقيع، ولا يعود أبداً إلى مفتاح debug.
بناء debug لا يحتاج مفتاحاً.

1. انسخ `android/key.properties.example` إلى `android/key.properties` واملأ
   القيم، وضع ملف الـ keystore في `android/` (كلاهما متجاهَل في git)؛
2. أو عرّف متغيرات البيئة `WASELNET_OWNER_UPLOAD_STORE_FILE` و
   `WASELNET_OWNER_UPLOAD_STORE_PASSWORD` و `WASELNET_OWNER_UPLOAD_KEY_ALIAS` و
   `WASELNET_OWNER_UPLOAD_KEY_PASSWORD`.

```bash
flutter build appbundle --release
```
